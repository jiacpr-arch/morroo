# LINE rich menu — หมอรู้ (@901nmwcd)

เมนูเดียวสำหรับทุกคน ฝั่ง server ตัดสินระดับเอง — ใช้ grid เดียวกับรู้ดี (roodee) เพื่อให้
เมนูของ 3 แบรนด์ (รู้ดี / หมอรู้ / ฟาร์มรู้) หน้าตาและตำแหน่งปุ่มเหมือนกัน
โค้ด: `lib/line-menu.ts` · ติดตั้ง: ปุ่ม "ติดตั้ง LINE rich menu" บน `/admin`

## Spec รูป (ส่งให้คนทำรูป / GPT)

- ขนาด **2500 × 1686 px**, JPG ≤ 1 MB → `public/line/rich-menu-main.jpg`
- เส้นแบ่งคอลัมน์ x = **0 / 835 / 1664 / 2500**, เส้นแบ่งแถว y = **0 / 724 / 1408 / 1686**
- สไตล์: การ์ดพาสเทลมุมมนแบบรู้ดี, ชื่อปุ่มตัวใหญ่ชิดล่างซ้าย + ลูกศร ›, เว้นขอบในแต่ละช่อง ~20 px

| แถว | ซ้าย (x 0–835) | กลาง (x 835–1664) | ขวา (x 1664–2500) |
|---|---|---|---|
| 1 (y 0–724) | 📝 **ข้อสอบวันนี้** | 🎯 **เปลี่ยนระดับสอบ** (ชิป: ส่วนที่ 1 · ส่วนที่ 2 · NL2 เดิม · MEQ + Long case · Board) | 🩺 **ฝึกทำข้อสอบ** |
| 2 (y 724–1408) | 📈 **ผลการเรียน** | 📅 **นับถอยหลังวันสอบ** | 💎 **แพ็กเกจ / ต่ออายุ** |
| 3 แถบล่าง (y 1408–1686) | โลโก้ **หมอรู้** | **รู้ดี** · ข้อสอบ ป.1–TCAS | **ฟาร์มรู้** · ข้อสอบ NL เภสัช |

## แต่ละปุ่มทำอะไร

| ปุ่ม | Action |
|---|---|
| ข้อสอบวันนี้ | postback `action=menu_today` → การ์ดข้อสอบวันนี้ตามระดับ (reply ฟรี ไม่กินโควต้า) |
| เปลี่ยนระดับสอบ | postback `action=level_menu` → quick reply ระดับ (`lib/line-level.ts`) |
| ฝึกทำข้อสอบ | LIFF `/practice` → MEQ ไป `/exams`, ระดับอื่นไป `/nl/practice` (เปิดตามระดับอัตโนมัติ) |
| ผลการเรียน | LIFF `/dashboard` |
| นับถอยหลังวันสอบ | LIFF `/nl/calendar` |
| แพ็กเกจ / ต่ออายุ | LIFF `/pricing` |
| หมอรู้ / รู้ดี / ฟาร์มรู้ | `morroo.com` / `roodee.me` / `pharmru.com` (+ utm) |

## ติดตั้ง

1. วางรูปที่ `public/line/rich-menu-main.jpg` แล้ว deploy
2. **ปิด rich menu ใน LINE OA Manager** (ไม่งั้นทับเมนูจาก API)
3. `/admin` → กด "ติดตั้ง LINE rich menu" (สร้าง → อัปโหลดรูป → ตั้ง default ทุกคน → ลบ `morroo-main*` เก่า)
4. ทดสอบกดครบ 9 ช่องในแชท OA

ถ้าเปลี่ยนตำแหน่งปุ่ม ต้องแก้ `COLS`/`ROWS`/`buildRichMenu()` ให้ตรงรูป และควรแก้ฝั่งรู้ดีให้ตรงกันด้วย
